# Ледяной трассер — визуальный предпросмотр

`icy-tracer-preview.png` — Blender-рендер на официальной геометрии AK-47 с нашим орнаментальным материалом. Луч начинается в геометрическом центре передней дульной кромки этой модели. Цвета и ширина берутся из `config/icy_tracers.json`. Это отдельный визуальный пример, не скриншот CS2 и не доказательство работы DLL.

Генератор: `tools/preview_icy_tracer.py`. Сначала нужны локальные модели из `tools/build_cs2_frost.py`; геометрия Valve не коммитится.

Игровой модуль и точная привязка: [docs/ICY_TRACERS.md](../../docs/ICY_TRACERS.md).
