# PEGASUS Frost Arsenal — материалы на оригинальной геометрии CS2

Новая версия заменяет отклонённые пользователем упрощённые прототипы.
Референс: предоставленное пользователем видео `PEGASUS_Frost_Arsenal.mp4`.
Все 12 OBJ взяты из официального пакета **CS2 weapon models** на странице Valve:
https://www.counter-strike.net/workshop/workshopresources

## Что создано

- `textures/ornament_atlas.png` — новый орнаментальный атлас по палитрам видео: снегири и рябина, еловой узор, сапфировые снежинки, звёзды и Пегасы. Атлас создан с помощью генерации изображений; это новая интерпретация рисунков, не исходные текстуры из видео.
- `textures/*_basecolor.png` — запечённые цветовые карты 2048×2048 в исходных UV каждого оружия.
- `renders/` — рендеры настоящих официальных mesh-моделей с новыми материалами.
- `manifest.json` — имена из видео, файлы, хеши исходников, геометрия и фактический статус.
- `../../tools/build_cs2_frost.py` — воспроизводимый импорт, назначение материалов, запекание, GLB-экспорт и рендер.

Форма, число вершин и исходная UV-развёртка сохраняются. Выполняются только жёсткий поворот, перенос и перевод дюймов в метры. Никаких условных силуэтов и замены геометрии нарисованной картинкой.

## Воспроизведение

```bash
python tools/fetch_cs2_workshop.py
blender --background --python tools/build_cs2_frost.py -- --source assets/cs2_local/source
python tools/compose_frost_board.py
blender --background --python tools/validate_cs2_frost.py -- assets/cs2_local/source
```

Геометрия Valve, производные GLB и упакованные Blender-сцены создаются в **`assets/cs2_local/`**; отдельные файлы этого каталога исключены из Git. По запросу пользователя полный пакет с моделями и сценами сохранён в репозитории как [archives/PEGASUS_Frost_Arsenal_FULL.zip](../../archives/PEGASUS_Frost_Arsenal_FULL.zip) через Git LFS. Текстуры, рендеры, манифест и инструменты также доступны отдельными файлами. Исходная геометрия принадлежит Valve; её источник — официальный архив для Workshop. Сборщик умеет скачивать его напрямую у Valve с проверкой SHA-256.

## Статус

Материалы реализованы в Blender; рендеры и GLB показывают фактическую геометрию.
Проверены все 12 моделей: координаты вершин после жёсткого преобразования, число граней и исходные UV совпадают с официальными OBJ. Проверены структура GLB, встроенные цветовые карты 2048×2048 и наличие рендеров. Результаты — в `validation.json`.
В Blender есть автономный мягкий перелив внутри светлых деталей узора с периодом 5 / 3,5 / 4 с. GLB содержит статический материал.

Нет компиляции VMat/VTex/VMDL, игрового теста CS2 и готового пакета для сервера. Официальные OBJ — геометрия для Workshop, без игрового рига и анимаций. Это не подтверждённый рабочий скин для установки на сервер.

Имена из видео используются только в этих визуальных материалах; действующий конфиг способностей и экономики не изменён.
