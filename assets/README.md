# 3D и материалы

Актуальная версия: [frost_cs2/README.md](frost_cs2/README.md). Орнаментальные материалы по видеореференсу запечены на исходных UV оригинальной геометрии из официального пакета Valve CS2 Workshop. Здесь сохранены новые текстуры, рендеры и манифест; геометрия и производные GLB/Blender-сцены создаются локально в исключённом из Git каталоге `cs2_local/`.

Упрощённые процедурные прототипы отклонены пользователем и заменены этим процессом. HTML в `/preview` остаётся ранним концептом и не является игровым ресурсом.

Source 2 материалы, компиляция и тестирование в CS2 ещё не выполнены. Перед переносом на весь игровой арсенал проверить один материал в игре.
