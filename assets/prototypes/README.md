# Зимний арсенал — 3D-прототипы v0.1

12 оригинальных стилизованных mesh-моделей, созданных процедурно в Blender.
Это ранние объёмные прототипы по концептам каталога, не точные копии игровых моделей.

- `*.glb`: отдельные модели с геометрией и статическими PBR-материалами.
- `arsenal.blend`: редактируемая общая сцена, свет и камера.
- `arsenal.png`: рендер этой сцены.
- `manifest.json`: перечень моделей; статус implemented, cs2_tested=false.
- Генератор: `../../tools/build_arsenal.py`.

Проверены структура GLB и наличие геометрии/материалов у всех 12 файлов.
Нет рига, анимаций, UV-развёртки для скинов, Source 2 материалов, компиляции и игровых тестов.
Декор и силуэты упрощены; тематические рисунки и точная детализация требуют дальнейшей работы.
Импортируйте GLB в Blender через File → Import → glTF 2.0.
