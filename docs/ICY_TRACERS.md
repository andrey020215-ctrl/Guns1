# Ледяные трассеры для конкретных экземпляров арсенала

Статус: **build_passed**, проверка в CS2 **не выполнена**. Референсы: предоставленные фото и `PEGASUS_Icy_Tracer.mp4`.

![Предпросмотр на оригинальной модели AK-47](../assets/icy_tracers/icy-tracer-preview.png)

## Поведение

Белое голубоватое ядро и более широкое голубое свечение живут 0,12 с и затухают. Эффект — две мировые beam-entity, без изменения урона, замедлений, звуков, подсветки игроков и кругов вокруг целей. Конфигурация: `config/icy_tracers.json`; предельное число одновременно существующих beam-entity — 192.

Трассер разрешён **только конкретному экземпляру** одного из 12 предметов арсенала, зарегистрированному доверенной серверной выдачей. Наличия VIP, покупки в меню или базового типа `weapon_ak47` недостаточно. Обычный AK-47/Glock и поднятый чужой экземпляр не получают эффект.

Ключ включает полный entity handle **с serial**, handle владельца и pawn текущей жизни, ID предмета и эпоху карты. Одинаковый индекс новой entity, переподключение, респавн и смена карты не наследуют привязку. Смена карты создаёт новую эпоху даже при том же имени карты.

На `weapon_fire` фиксируются именно стрелявший экземпляр, владелец, дульная точка и тик. На `bullet_impact` используются фактические координаты попадания. Выстрел из обычного оружия немедленно отменяет предыдущее ожидание; переключение без выстрела не переименовывает уже выпущенную пулю. Дробь ограничена нативным `NumBullets`, очереди Glock/FAMAS — `BurstShotCount`; повторы impact и дальнейшие пробития одиночной пули не порождают бесконечные лучи.

Начало берётся из **реального world-space muzzle attachment**, предоставленного адаптером установленной модели. Если attachment недоступен, эффекта нет: подставлять центр игрока, глаза или случайное смещение запрещено. Серверные ray trace ограничивают начало при стрельбе вплотную к укрытию и конец по первому препятствию. На ошибке trace не рисуется небезопасный луч сквозь стену. Если нет `bullet_impact`, модуль не выдумывает траекторию.

## Подключение выдачи и материалов

В этом репозитории покупка/выдача пока остаётся read-only контрактом. Модуль собран, но **сам не выдаёт, не помечает и не перекрашивает** стандартные оружия. До подключения реальной выдачи зарегистрированных экземпляров нет и трассеры не появляются.

1. Общую `PegasusVipArsenal.Contracts.dll` поместить в `addons/counterstrikesharp/shared/PegasusVipArsenal.Contracts/`; обе интеграции должны использовать этот общий тип.
2. После фактической выдачи, применения именно нашего материала и экипировки получить capability `pegasus:arsenal-effects:v1` типа `IArsenalEffectsApi`.
3. Зарегистрировать receipt с новым `GrantId`, текущим `MapEpoch`, полными handle контроллера/pawn/оружия и ID предмета. Сервис проверяет реальное владение, наличие предмета в инвентаре и совпадение базового типа с каталогом. Передать resolver, который на момент выстрела читает дульный attachment этого экземпляра.
4. При откате выдачи, снятии/замене скина или замене предмета вызвать `Revoke(handle)`; при выходе, смерти, удалении entity и смене карты очистка встроена.
5. Все вызовы — в игровом потоке. Capability нужно получать заново после hot reload; старый сервис деактивируется. Стабильный provider в общей DLL возвращает новый сервис и не удерживает старый экземпляр плагина.

Пример в доверенном адаптере выдачи (не команда игрока):

```csharp
var effects = new PluginCapability<IArsenalEffectsApi>(IArsenalEffectsApi.CapabilityName).Get();
if (effects is null) return;
var receipt = new ArsenalWeaponReceipt(
    grantTransactionId, effects.MapEpoch,
    player.EntityHandle.Raw, pawn.EntityHandle.Raw, weapon.EntityHandle.Raw, catalogItem.Id);
var registered = effects.RegisterGranted(receipt, query =>
    modelAdapter.TryGetWorldMuzzle(query.WeaponHandle, query.PawnHandle, query.Tick));
// modelAdapter — адаптер реальной модели сервера, не выдуманный метод CounterStrikeSharp.
// null => attachment недоступен, пропустить трассер. При rollback: effects.Revoke(weaponHandle).
```

Дубли с **Weapon Frost Effects**: у каждого зарегистрированного экземпляра должен быть один renderer. В его существующем обработчике необходимо пропускать собственный трассер, если `effects.OwnsTracer(weaponHandle)` возвращает `true`. Для остальных оружий этот модуль ничего не включает. Автоматического изменения неизвестного внешнего плагина нет; совместную конфигурацию проверить на тестовом сервере.

## Сборка и проверки

Сборка закреплена на официальном **CounterStrikeSharp.API 1.0.378**, `net10.0`, SDK .NET 10. Типы и свойства сверены с тегом `v1.0.378` исходников CounterStrikeSharp. Это опорная версия для сборки, **не установленная версия PEGASUS**, которая здесь неизвестна. Путь к DLL сервера по-прежнему можно передать через `CounterStrikeSharpApiPath`, но совместимость другой версии требует повторной сборки и теста.

```bash
dotnet build src/PegasusVipArsenal/PegasusVipArsenal.csproj -c Release
dotnet run --project tests/IcyTracerTests/IcyTracerTests.csproj -c Release
dotnet run --project tests/PolicyTests.csproj -c Release
python tests/test_catalog.py
```

Тесты состояния используют .NET 8, плагин — .NET 10. DLL и SDK в Git не коммитятся. Автотесты проверяют привязку, события, очистку и лимиты; они не подтверждают внешний вид или фактический порядок игровых событий в CS2.

## Приёмка в CS2, ещё не пройдена

- Поочерёдно выстрелить из каждого из 12 оформленных экземпляров; обычные копии тех же базовых оружий, игрок без регистрации и чужой владелец остаются без нового трассера.
- Проверить POV первого/третьего лица, правильный attachment при глушителе и в движении, очереди, все дробинки, пробития, небо, выстрел вблизи стены и смену оружия между fire/impact.
- Проверить снятие скина, revoke/rollback, смерть, удаление, повторное использование индекса, смену карты, hot reload и отсутствие дублей Weapon Frost Effects.
- Подтвердить видимость стандартной `beam`, ширину/цвет/затухание и depth test именно в CS2. При необходимости выбрать поддерживаемый материал в установленной сборке; работоспособность стандартного beam пока подтверждена только компиляцией API, не игровым рендером.
- Нагрузочный тест 32 игроков, Negev и дробовиков; все beam удаляются и не накапливаются после разгрузки плагина. Достигнутый бюджет приводит к пропуску косметического эффекта, не к изменению выстрела.

Действующий сервер PEGASUS не изменялся. Установка и игровой тест требуют отдельного согласования по `AGENTS.md`.
