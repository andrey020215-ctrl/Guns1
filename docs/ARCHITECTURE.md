# Архитектура, этапы разработки

- **WeaponCatalog** — валидация и чтение 12 записей, три уровня VIP.
- **VipAccess** — локальные SteamID64-файлы (перенос на основную систему PEGASUS только через адаптер).
- **WeaponGrantService** — общая транзакционная выдача из магазина и VIP-меню. Должна выполнить проверку, создание entity, замену слота, экипировку и окончательное списание средств или откат. См. [контракт](INSTANT_GRANT_RU.md).
- **AbilityEngine** — изолированные 12 механик, кулдауны, события, очистка состояния.
- **MaterialEffects** — привязка модели и текущего VIP-финиша, клиентская анимация Source 2.
- **IcyTracerState / IcyTracerController / IcyBeamRenderer** — привязка трассеров к конкретным выданным экземплярам и пара `weapon_fire → bullet_impact`. Реализовано и собрано на API 1.0.378; нужен адаптер реальной выдачи/материалов и тест в CS2. Контракт интеграции: [ICY_TRACERS.md](ICY_TRACERS.md).
- **ShopAdapter** — внешний интерфейс списания снежинок без двойного списания; интерфейс интеграции с существующим магазином ещё уточнить.

В исходниках есть read-only каталог, проверка VIP и модуль трассеров. Выдача и применение материалов пока не интегрированы; без регистрации настоящего оформленного экземпляра трассеры не включаются. Никакие grants не должны запускаться, пока не будут связаны с актуальной версией CounterStrikeSharp и проверены на локальном сервере. Не изменять сервер PEGASUS и не подключать pickup механики.
