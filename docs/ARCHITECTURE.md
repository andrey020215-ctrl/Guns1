# Архитектура

- `WeaponCatalog`: конфигурация 12 предметов, уровни VIP, цены и способности.
- `VipAccess`: начальный адаптер SteamID64 файлов; заменить подключением к существующей системе прав.
- `MapWeaponStore`: уже написанная тестируемая доменная политика доступ/покупка/сброс на карте. **Не подключена к событию CS2 OnMapStart.**
- `ISnowflakeWallet`: контракт атомарного списания через существующую экономику PEGASUS. **Реального wallet-адаптера ещё нет.**
- `WeaponGrantService` (TODO): реальная выдача по кнопке «Взять», серверная проверка доступа, совместимость с CS2.
- `MenuBridge` (TODO): VIP-меню отдельно, обычный магазин отдельно.
- `AbilityEngine` (TODO): игровые события, кулдауны, буферы попаданий, очистка на смене карты/смерти.
- `MaterialEffects` (TODO): модель/скин, анимация Source 2, влияние VIP на шейдер; browser preview не игровой материал.

Для надёжной покупки при рестарте сервера потребуются карта/эпоха и персистентный журнал приобретений. В текущей доменной реализации память процесса очищается после рестарта.

НЕ использовать авторитет клиента для проверки покупки или списания.
