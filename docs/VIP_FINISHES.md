# Три анимированных зимних материала

| Уровень владельца | Вид | Палитра | Цикл |
|---|---|---|---|
| VIP I | Иней — мягкая перламутровая бело-голубая волна | #f6fdff / #79cfff | 5 с |
| VIP II | Метель — голубые и бирюзовые бегущие прожилки | #64caff / #20decf | 3,5 с |
| VIP III | Аврора — волны северного сияния | #3fa9ff / #14d6c7 / #8c54e9 | 4 с |

Требование: движение **само**, даже когда игрок стоит неподвижно. Но стабильная поддержка анимации в материалах Source 2 для реальных пользовательских моделей не подтверждена. Проверить на одном прототипе в игре, затем масштабировать на 12 оружий. Не подменять 3D-модель 2D-рендером. Ограничивать яркость, движение только внутри узоров, читабельность и стоимость кадров. VIP III должен давать свой перелив любому оружию из разрешённых младших коллекций. HTML-превью в /preview — только концепт.
