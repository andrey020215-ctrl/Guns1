# PEGASUS CS2 — VIP Winter Arsenal

**Независимый проект:** 12 зимних VIP-оружий (9 основных + Glock-18, USP-S, Desert Eagle), 3 анимированных вида переливов и особые способности на C# / CounterStrikeSharp.

> **Стадия:** исходный C#-каркас + проверяемые данные + HTML-прототип. **Не** готовая DLL и **не** завершённые Source 2 модели. Плагины, способности и переливы в самой CS2 ещё не испытаны. Действующий сервер PEGASUS не меняем.

## Арсенал

| VIP | Основные | Пистолет | Динамический материал |
|---|---|---|---|
| I «Иней» | MP9 «Снегирь», FAMAS «Снежный дозор», Nova «Хрусталь» | Glock-18 «Морозный импульс» | Бело-голубой перламутр, 5 с |
| II «Метель» | AK-47 «Frostbite», M4A1-S «Blizzard», SSG 08 «Полярный след» | USP-S «Призрачный иней» | Голубые/бирюзовые прожилки, 3,5 с |
| III «Аврора» | AWP «Ice Dragon», XM1014 «Вьюжный клык», Negev «Вечная мерзлота» | Desert Eagle «Полярная буря» | Северное сияние: голубой/бирюзовый/фиолетовый, 4 с |

VIP владельца определяет финиш любой доступной модели, даже из младших коллекций. Полные механики и лимиты — [каталог](config/vip_weapons.concept.json), [описание](docs/WEAPONS.md) и [задание Codex](CODEX_TASK_RU.md).

- [Первоначальный концепт](preview/pegasus-winter-arsenal.html) — оригинальный лист девяти основных оружий.
- [Каркас CounterStrikeSharp](src/PegasusVipArsenal) — каталог из JSON, проверка прав VIP и команда только для просмотра арсенала (`css_vipguns`). Выдача и боевые способности ещё **не реализованы**, чтобы не выдавать фиктивный результат.
- [Тестирование данных](tests/test_catalog.py) — проверка 12 имён, уровня доступа, уникальности оружия, ссылок на базовые CS2 weapon-имена, параметров перелива.

## Локально

```sh
python3 tests/test_catalog.py
# Сборка плагина на машине, где установлены .NET 8 SDK и CounterStrikeSharp API:
dotnet build src/PegasusVipArsenal/PegasusVipArsenal.csproj -p:CounterStrikeSharpApiPath="C:/path/to/CounterStrikeSharp.API.dll"
```

`CounterStrikeSharpApiPath` нужно передать явно; пакет и API-версию следует сверить с текущим сервером. Нет DLL → нет заявления о рабочем плагине. Исходный проект намеренно не меняет основной сервер. После установки тестовой DLL в CounterStrikeSharp: `css_vipguns` и `connect 127.0.0.1:27015`.

## Рабочий процесс Codex

Откройте `AGENTS.md`, затем `CODEX_TASK_RU.md`. Поэтапно делайте PR: проверка сборки → выдача через меню «Взять» → способности → модель/материал для каждого уровня → игра на локальном сервере. **Не** отключать античит, не писать в рабочую папку PEGASUS и не добавлять SteamID настоящих игроков в публичный GitHub.

## Мгновенная выдача

Покупка за снежинки и кнопка VIP «Взять» должны выдавать и экипировать оружие **сразу в текущей жизни**, без респавна. См. [спецификацию](docs/INSTANT_GRANT_RU.md). В данной версии это только обязательное требование: настоящий grant ещё не реализован.
