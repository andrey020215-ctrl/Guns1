# Правила работы Codex в Guns1

- Изменения и созданные результаты сразу отправлять в GitHub через PR; не ограничиваться локальными файлами или ссылкой на скачивание в чате. Большие полные архивы сохранять в репозитории через Git LFS, с явной пометкой фактического статуса сборки и игровых тестов.
- **Действующий сервер PEGASUS не менять**. Тестовую установку делать только после отдельного согласования.
- НЕ объявлять готовыми DLL, модель, динамический материал или способность, пока не пройдены сборка и тест в CS2.
- Сначала открыть `CODEX_TASK_RU.md`, `docs/ACCESS_AND_ECONOMY.md` и `config/vip_weapons.concept.json`.
- Все 12 оружий доступны в **обычном магазине за снежинки**: 4 в каждой VIP-коллекции.
- VIP I получает бесплатно I, VIP II — I+II, VIP III — I+II+III; более высокий набор можно покупать в обычном магазине.
- **Покупка действительна до следующей смены карты**, не до смерти. Баланс не сбрасывать при смене карты.
- Повторное «Взять» по купленному предмету не списывает деньги; покупка по одинаковому запросу идемпотентна.
- **Существующая экономика PEGASUS является источником истины**. Никаких второй валюты и непосредственного редактирования баланса в данном плагине.
- Динамический перелив зависит от текущего уровня VIP владельца; у обычных покупателей — родной финиш коллекции.
- Текст сообщений: «Вы купили <название> за N снежинок», «Вы взяли <название>».
- Каждому оружию свой cooldown; нейтрализовать накопление замедлений и проверить 110 HP / 125 брони.
- Зависимость CounterStrikeSharp API проверять на конкретной версии; не писать выдуманные хуки.
- Не коммитить личные SteamID, игровые ресурсы без лицензии и секреты; выпускать изменения через PR.
- Статус задач: `planned`, `implemented`, `build_passed`, `cs2_tested` (без ложных пометок).
