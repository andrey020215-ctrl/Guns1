# Локальные права VIP (только тест)

Положите рядом с DLL папку config/roles с файлами vip1.txt, vip2.txt, vip3.txt: SteamID64 по одному на строку; # комментарии. Настоящие SteamID не коммитить! Один человек в нескольких списках получает максимальный уровень. Для основного PEGASUS позже потребуется адаптер его системы прав.
