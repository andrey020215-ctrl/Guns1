# VIP Role IDs

Тестовый формат: `vip1.txt`, `vip2.txt`, `vip3.txt`; по одному SteamID64 на строке. Эти файлы **игнорируются Git**, так как содержат персональные идентификаторы.

В продакшене интегрировать с уже существующими VIP/Admin/Dev файлами и роль-сервисом PEGASUS, не заводить вторую систему прав.
